# 客户演示脚本（约 5 分钟）

## 目标

让客户看到“留言表 → 可审核线索 → 可下载结果”的完整闭环，不把规则演示误说成模型准确率承诺。

## 流程

1. 打开产品，点击“载入示例数据”。说明 `demo-contact-001` 等是合成标识。
2. 在“行业预设”选择“电商咨询”，保存设置；说明预设只是客户校准起点。
3. 选择“演示规则”并开始处理。展示高/中/低意向和“线索漏斗（仅当前会话）”。
4. 选择一行，把阶段从“新线索”改成“已联系”；采用 AI 草稿，人工编辑一句不含价格/交期承诺的回复，点击“保存并确认”。
5. 下载“全部结果（草稿）”和“可发送结果”，打开工作簿说明水印、原始行号和人工确认门槛。
6. 点出边界：不会自动登录店铺、自动发送或保存历史；真实 AI 需客户确认数据合规和费用。

## 可报价模块

- 模板字段映射与客户标签校准；
- 行业预设、禁词和回复语气配置；
- Excel/CSV 导入、漏斗字段和人工复核导出；
- 受控环境下的 OpenAI 兼容 API 接入（费用、数据留存另行确认）。
